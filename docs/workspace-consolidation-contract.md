# Clinic workspace coordination contract

The canonical administrative clinic detail route remains `/admin/settings?clinicId=<id>&section=<key>` with sections `general`, `locations`, `sessions`, `policies`, `staff`, `qrs`, `history`. Existing `/admin/clinics`, `/admin/branches`, `/admin/users`, `/admin/qrs`, `/admin/audit`, `/admin/availability`, and `/admin/exceptions` deep links must remain functional. Navigation may send users to the canonical workspace; do not change public booking/QR URLs.

`ClinicSettings.tsx` (owned by clinic-workspace agent) will import the existing `ResourcePage` from `resources.tsx` to render real scoped embedded resource listings, rather than intermediate link-only cards. **ResourcePage agent:** add optional props `embedded?: boolean` and `fixedClinicId?: string` to `ResourcePage`. For `fixedClinicId` omit the removable clinic filter and enforce clinicId in actual API request parameters and create defaults so a user cannot accidentally view/create outside the selected clinic. When embedded, suppress duplicate page headings only; preserve Add, edit, QR actions, paging and authorization. Resource names: `branches` for location list (clinic-workspace agent keeps existing settings hours/linked consultation editor as authoritative), `users` is a separate `Users` component so clinic-workspace agent will embed `<Users identity={identity} clinicId={clinicId} embedded/>` only if Users agent agrees, otherwise scoped staff link until API supports safe embedded editor; `qrs`, `audit` for QR/history. Please add resource prop without importing ClinicSettings and report any unavailable resource scope.

`ClinicSettings` uses a vertical section menu or labelled small-screen select (not status-style tabs), preserving clinicId+section in URL and owner-only settings write authorization. `SchedulingWorkspace` is the one weekly/exception workflow, used by `/admin/availability` and the clinic workspace's Doctors & Sessions section. Its collapsed `ClinicSessionSetup` helper copies opening hours only for custom sessions; linked owner hours still use the protected location preview editor. The former `/admin/exceptions` remains accessible via schedule section selector, preserving context via existing URL query parameters. Former resource paths remain routable and supported for old bookmarks. Editing `/admin/branches` routes to clinic settings with branchId; the settings editor consumes that parameter on close or save.

Do not conflate staff assignment, patients, doctor clinical status, location opening hours, and bookable doctor sessions into one record. Do not automatically delete, duplicate or migrate any customer data. Interface consolidation only.
