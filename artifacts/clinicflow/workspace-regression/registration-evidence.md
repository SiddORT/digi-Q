# Clinic registration verification (fictional fixtures only)

- Browser journey: `pnpm --dir artifacts/clinicflow exec playwright test --config workspace-regression/playwright.config.ts onboarding.spec.ts`. The isolated `?mode=onboarding` fixture renders the real account and registration components with intercepted `/api` requests. It exercises stage navigation, session drafts and reload, safe blocked-storage fallback, locality toggling, independent inherited contacts, day/session editing, copy replacement confirmation, owner linked/custom schedule selection, review and one completion request, plus successful and failed OTP resend. The account fixture never sends email or creates an actual account.
- Rendered screenshots: `artifacts/clinicflow/screenshots/registration/{1366,768,390}-{location,hours}.png` and `review.png`. These represent fictional data; stage-two labels, URL suggestions, contact inputs, day controls, exact times and action layout are visible without claiming a signed-in UAT clinic was visited. The toast dismiss control is checked for a circular 44 × 44 pixel target in the browser run.
- Backend: `registration-onboarding.integration.test.mjs` uses disposable multi-connection PostgreSQL and intercepted mail. It verifies independent effective contact requirements, atomic linked/custom owner sessions, concurrent requests, authorized completion reads, changed-payload rejection, password recheck and lost-response retry. `auth-contention.integration.test.mjs` checks resend rotation, failed delivery preserving the old code, cooldown/expiry/rate limits and challenge resume identity. No live mail or real UAT database is touched.
- The main shared CTA primitives (`FormActions` and `LoadingButton`) plus onboarding actions now add labeled leading icons unless the consumer supplies an icon. Legacy bespoke actions elsewhere in the application have **not** been individually redesigned.
- **Live-UAT limitation:** Neither an authenticated browser session against the real `/register-clinic` deployment nor inbox delivery was performed. The supplied screenshot gaps were checked against the current rendered fictional journey rather than attributed to an unproven live root cause. Do not interpret fixture evidence as authorization to modify live clinics or deploy.
