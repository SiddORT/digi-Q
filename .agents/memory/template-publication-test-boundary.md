---
name: Template publication and optional tests
description: Wording publication must remain independent of unfinished or invalid optional test inputs.
---

Publishing notification wording does not require a test recipient, test placeholder values, or a prior preview/test. Optional tests keep their own completeness, validation and explicit-consent requirements.

**Why:** The user requires valid saved SMS and Email drafts to publish with Advanced either open or closed, without enabling delivery or sending anything. Collapsed controls still participate in browser constraint validation unless their form ownership is separated.

**How to apply:** Preserve template-owned validation and shared date/time validity. Treat the optional test panel as a separate validation boundary, not a reason to disable browser validation for the entire wording form.
