---
name: Clinic workspace product boundary
description: Informational management label and distinct private versus public clinic URL identities
---

Clinic-wide Management is informational only and should stay visually minor.
Use the existing accessible help pattern; do not invent a management destination.

**Why:** The user explicitly clarified that the reference image's apparent
management-button requirement is not an action requirement.

**How to apply:** Preserve this distinction when revising Clinic Details or
sharing its overview with other authorized roles.

Private clinic workspace links use stable authoritative record IDs. Public
clinic/location links reuse the already-persisted slugs; neither names nor a
second slug system should replace either identity.

**Why:** The user requires readable private sections without breaking saved
public links, printed QR codes, opaque references or existing ownership rules.

**How to apply:** Change link presentation and compatible route resolution,
not stored slugs, database keys, token contracts, domains or authorization.
